### B-01 受控来源协议与固定身份

- **前置：** B-00 已选合成来源；严格允许消息类型及适配器边界。
- **最小产物：** 版本化来源信封和适配器接口：持久 namespace、带类型 source ID、种类、目标、UTF-8 正文/大小/摘要；稳定 ID 在重启、重读、恢复时不变。源原生确认接口与核心 `confirm_source` 分开。
- **模块：** 拟新增来源适配模块；`routing.py`、`routing_commands.py`、`tests_v3/test_routing.py`；适配层保留源语义，不向基座加业务名分支。
- **不做：** 扫旧 inbox、正文指令转任务、将路径/当前时间当唯一身份、静默截断长正文。
- **测试：** `1` 与 `"1"`、重复同文/异文、Unicode/换行/边界大小、未知种类、重启后 ID 稳定；相同来源只有一个 admission 和 Task。
- **证据：** 协议样本、冲突错误及完整 ID 链；所有样本标合成、不含传输令牌。
- **回退/停止：** 无法提供稳定 ID 或原生确认语义时拒绝接入，源保留待处理状态。

### B-02 目的端准入预检

- **前置：** B-01 固定来源与目标；已有 `ReceiptStore` 和绑定守卫。
- **最小产物：** 在接受可执行任务前校验目的端协议、namespace/id、root/instance 和字节限额，并固定可审计的准入快照；发送前复核同一目标。当前核心只在首次 claim_delivery 绑定，需明确补充适配层预检及变化处理契约。
- **模块：** `receipt_store.py: descriptor`、`deliveries.py`、`routing.py` 及拟新增部署/适配配置；若新增持久字段先显式版本化。
- **不做：** 依目录存在就认为支持 receipt；不等模型已完成才发现目的端协议根本不支持；不把预检当接收证据。
- **测试：** 协议/限额错误在执行前拒绝；预检后替换根/instance、同名空目录、路径别名不能继续投递；合理网络/IO失败保持明确不可用。
- **证据：** 预检输出白名单、失败时零 Attempt、变化时 held/拒绝及完整平台结果保留。
- **回退/停止：** 目标不可确认则停止新接纳或保持明确未执行队列；不得换目标解除 held，不重跑模型。

### B-03 源搬运单步与确认恢复

- **前置：** B-01/B-02 通过；明确先接纳再源确认顺序。
- **最小产物：** 一次搬运调用 `claim_source → admit_source → 源原生确认 → confirm_source`。最后一步只记录已发生事实，不代替源确认。重复处理查回原 admission；源确认失败可恢复，不新建 Task。
- **模块：** 来源适配模块、`routing.py: claim_source/renew_source/admit_source/confirm_source`；拟新增适配集成测试。
- **不做：** 跨源和核心假装一个事务；不先确认后接纳；不在核心事务内等外部确认。
- **测试：** 接纳前、接纳后/源确认前、源确认后/平台标记前强制中断，再启动；namespace/source ID/admission/Task 保持一致。旧 token/epoch、续租过期、源确认超时分别验证。
- **证据：** 每个崩溃点前后持久状态与唯一计数；源确认返回结果与平台 source_confirmed 对齐。
- **回退/停止：** 原生确认结果不明时仅核对原来源，保留可恢复记录；不能标确认或重新执行。

### B-04 消费者执行授权与恢复 fence

- **前置：** B-03 可重放；B-00 中每个参与消费者可控制。
- **最小产物：** 每条执行路径在拉起原生执行或向会话投递前，获得核心授权并校验固定 lane、代次、owner、claim epoch/token 和租约。V3 共用 `_claim`；旧线适配使用 `claim_legacy/renew_legacy`，不把来源搬运 lease 当执行权。批次中逐项验证。
- **模块：** `routing.py`、`service.py`、`members.py`；仅改 B-00 已纳入的旧消费者函数；禁止更改无关在线部署。
- **不做：** 根据配置开关、文件锁、同 PID/同角色名执行；不让过期执行自动重新发送原生输入。
- **测试：** 两线/两个进程争同一来源；freeze、epoch 切换、旧 lease 延迟、初始 drain/执行中 wait/恢复批次；只有一个授权执行，迟到方不能产生新 Attempt 或投递。
- **证据：** 每个参与入口独立测试 ID、共同守卫位置、执行启动/原生投递调用计数；未适配入口明确拒绝或留旧线。
- **回退/停止：** 找到一条旁路即冻结该来源的新接纳/claim；原执行未知时保留 held，不宣布排他完成。

- **不做：** 解析普通模型正文派活、自动把子任务继承父所有权限、把 B 预编排称自主协作。
- **测试：** 未授权工具拒绝、循环/重复请求、子任务结果迟到、父停止、等待期补充、新代次旧结果错投；真实协作按能力独立验收。
- **证据：** 原生请求到平台对象和结果输入的完整公开 ID 链；替身与真实范围分别记载。
- **回退/停止：** 权限或父子归属不明拒绝调用，保留平台控制方预编排能力。
