# 全功能自我迭代宪章(Self-Redesign Charter)

> **用户授权 2026-09-16(原话)**:"全功能的自我迭代,你可以将所有功能都进行重设计,this is everyone module,为了更好而重构造,但是业务和基建分离,永远在线是铁率(律)"。
> 即:**所有模块**都可为更好而重设计/重构造;两条铁律不可违。

## 两条铁律(每个重设计提案的硬闸)

### 铁律1:业务 / 基建分离(separation)
- 承接 `bus-pluggable-business-platform`:bus=通用 agent 管理平台,业务=可插拔负载。
- **三问验收**每案必过:①归属问(这是机制还是业务内容?)②清除问(业务清完平台能空载跑?)③换域问(换业务域要改平台代码?)。
- 重设计**不得**把业务口径/数据焊进平台代码;业务内容一律业务侧存储 + `path_registry.json` biz-data 登记。

### 铁律2:永远在线(always-online)
- **任何重构不允许下线/失联**:协作频道(事件自醒·轻问·可打断)在重构全程保持可用。
- 落地方式=**增量绞杀(strangler)、禁大爆炸切换**:双跑期新旧并存,切换=灰度非一刀切。
- **★接管硬门槛(Master数分 P0·实证方定·缺一不接管)**——"新机制实证接管"非口号,全绿才算:
  ①双跑≥N 个**真实周期**(非造样本·N 按机制关键度定·协作频道类≥1 周);
  ②行为对比:新旧对【同一真实历史输入】输出一致率≥阈值(探针作回归仪·辩证正/反/合);
  ③探针回归全绿(无方向性错误新增);
  ④**Master数分对抗签字**(非 owner 自评——daemon 化翻车根源=自证);
  ⑤在线性指标未破(协作往返延迟/可打断响应≤基线)。
- **反例镜鉴**:2026-08-27 daemon 化=一次性全舰切换 + "不失能"靠自证→协作频道退化→全面回退。
- 迁移类动作沿用铁序:**先广播 → 动刀 → 再确认**(消费方知情·瞬时窗口有预告)。

## 流程(每模块一案)
1. **Inventory**:以 `bus_mechanisms.json`(96 机制/13 类注册表)+ UI/hook/记忆/探针面为全集,各 owner 盘自己 lane 的重设计候选(痛点/debt/更优形态)。
2. **提案(proposal)**:痛点→新形态→迁移路径(如何保在线)→验收判据。
3. **三闸 gate**(过不了不动工·**每闸 PASS 须实证方(Master数分)独立签字**·提案 owner 不得自评自己的闸=P1):
   ①核心价值闸(强化还是削弱"便宜协作+可打断"?**度量 proxy**:轻问往返延迟/可打断响应时间/协作 token 成本=P3);
   ②分离闸(铁律1三问·清除问=**真跑一次空载启动测试**非口头答=P3;**双跑过渡期的桥接代码同受三问约束**·不得临时焊业务=P4);
   ③在线闸(铁律2·双跑/灰度方案齐备 + **预声明回滚触发线**=P2:探针回归转红/协作延迟超限/在线性破任一→**触即自动回旧**·非事后 panic)。
4. **增量执行**:小步提交·每步 smoke(bus_smoke/ui_smoke 金标准)·可回滚(回滚线已预声明)。
5. **实证验收**:Master数分对抗验证(非自证);接管按铁律2硬门槛五条全绿。
6. **发版记录**:机制改动照常 genesis + tag(MasterAgent 自动发版·大版本目标用户定)。

## escalate 判据(常任授权下·决策 vs 执行=P5)
承接会问 doctrine:触及【不可逆 / 跨 agent 契约变更 / 在线性赌注】=**决策 → escalate 用户**(非阻塞待办池);
规定动作/可逆/零风险=**执行·过三闸直做不问**。拿不准=当决策。

## 与迭代波的关系
迭代波 v1(仪器驱动:探针/记忆/缺席)是本宪章的**运行态采样层**——探针 verdict / 记忆 trap 实证 / 阈值实测持续喂重设计候选。宪章把「发现→重设计→验证→发版」闭成常态循环:**fleet 自己迭代自己,用户只拍大方向**。
