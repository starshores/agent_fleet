# 关于本仓（About This Repository）

> 本文件说明本仓的历史口径、AI 参与、作者身份、定位与许可证状态，供读者在阅读提交历史前先了解背景。

## 历史为重建 / 回放

本仓的提交历史按原始工程时间线重建（或回放）而成：提交顺序与提交时间戳按原工程时间线回填，并非自然发生的实时提交。提交消息、文件内容与 tag 用于保留工程演进轨迹；阅读时请以“重建后的历史”而非“原始实时记录”理解。

## AI 参与

提交正文中的 `Generated-by:` 行记录该提交的生成来源，包括 Claude 等生成模型，以及 MasterUI / Master数分 等协作角色；这些署名是真实归属，未做隐藏。

## 作者身份

本仓所有提交统一使用发布署名 `starshores <unrealdreaminempty@gemil>`，不暴露真实姓名。该署名与托管平台账号的关联关系以 GitHub 页面显示为准；如后续改用 `noreply` 地址，会在此说明。

## 仓库定位与状态

本仓是 BUS 2.x 的协调基础设施（agent bus / WebUI / hooks / 运行态支撑）。`main` 为 Claude Code 主力使用版本；`codex/masteragent-3-boundary` 为 Codex 预览版（MasterAgent 3.x），功能暂不完善，不建议用于生产。当前定位为内部工程演进仓，不是可直接对外交付的业务仓；随仓文档中的路径、角色配置与运行态字段用于说明机制，具体部署按 `CLAUDE.md` 的迁移 / 换机清单调整。

## 提交消息中的历史短 hash

提交消息中少量短 hash 在本仓对象库中无法解析。它们指向重建前的历史或其他 bus 实例的提交，不是本仓的提交对象；这是历史事实，不影响本仓当前代码运行。
